## 🧠 How I work

- **Offline first.** Apps should work with no internet and no sign-up.
- **Two languages.** Hindi and English, because that is how my family actually talks.
- **Trust the data.** In MoneyNest, balances are never stored as a single number. They are rebuilt from history, so nothing silently drifts.
- **Test and automate.** I use GitHub Actions to build and test my apps on every change.
- **Security matters.** I keep my money app private while I harden it: login protection, backup safety and data handling.
